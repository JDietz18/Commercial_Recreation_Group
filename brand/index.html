13 / Build

Applying to Intera

skin-1.css declares these variables, but most of its rules use hard-coded hex values. Replace the hex values as well, not only the variables.

skin-1.cssInteraCRG
--bg-color#ffa200#F25422
--bg-color-sc#ff6c00#D2410C
--bg-color-ho#91ae1d#68BE32
--text-color#ffa200#A82F00
--text-color-sc#b056ff#1E59CD
borders#a8ca1e#F25422
HeadingsMontserrat, Poppins → Barlow Condensed
BodyOpen Sans, Roboto → Barlow
Icons4 icon fonts → Lucide
  • css/crg-tokens.cssEvery color, ramp, type size and theme value as CSS variables. Load first.
  • css/crg-base.cssType classes, buttons, icons, theme-aware logo swap.
  • css/skin-crg.cssReplaces Intera's skin-1.css. Maps its variables and fonts to CRG.
  • js/theme.jsLight/dark toggle that follows the device until a visitor chooses.
  • icons/sprite.svgThe Lucide icons used here, as one sprite.
/* css/skin/skin-crg.css */
:root {
  --bg-color:      var(--crg-primary);       /* #F25422 */
  --bg-color-sc:   var(--crg-primary-hover); /* #D2410C */
  --bg-color-ho:   var(--crg-accent-1);      /* #68BE32 */
  --text-color:    var(--crg-primary-text);  /* #A82F00 */
  --text-color-sc: var(--crg-accent-2-text); /* #1E59CD */
}
h1,h2,h3,h4 { font-family: var(--crg-display); }
body        { font-family: var(--crg-body); }
